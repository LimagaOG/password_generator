## 📌 About The Project
**Quick Password Generator** is a fast and secure browser extension designed to help you create robust passwords and test the security level of existing ones instantly in a clean popup interface.

---

## ✨ Features
* 🔐 **Secure Generation**: Instantly generate randomized passwords with letters, numbers, and symbols.
* 📊 **Real-Time Strength Checker**: Type any password to evaluate its strength (Weak, Medium, Strong) dynamically.
* ⚡ **Lightweight UI**: Fast performance with a modern dark theme.

---

## 📥 Download & Install Instructions

1. 1. **[Click Here to Download the ZIP File](https://github.com/LimagaOG/password_generator/raw/main/PasswordGeneratorRiswan.zip)**
2. Unzip or extract the downloaded `.zip` file into a folder on your computer.
3. Open your browser and go to `chrome://extensions/`.
4. Turn on **Developer mode** using the toggle switch in the top-right corner.
5. Click the **Load unpacked** button in the top-left corner.
6. Select your extracted extension folder.

🎉 **Done!** The extension is ready to use in your toolbar.
